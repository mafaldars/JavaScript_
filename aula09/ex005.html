DOM é o modelo de objetos para documentos. É um conjunto de objetos dentro do navegador para dar acessos aos componentes internos dentro do site.

Árvore DOM

Tudo dentro do JS esta inserido na window.
window (objecto)
location (url, navegador, página atual)
document (documento atual)
history (guarda de onde veio para onde vai)

Dentro de document: html parent (parent do head and child. Child de document)
head child (meta title)
body child (h1 p div)

Podemos navegar dentro do DOM da maneira que achamos melhor. Existem várias maneiras de navegar entre os elementos.

MÉTODOS DE ACESSO AO DOM
por Marca (tags) | getElementsByTagName()
por ID | getElementById()
por Nome | getElementsByName
por Classe | getElementsByClassName
por Seletor | querySelector() | querySelectroAll (CSS)
